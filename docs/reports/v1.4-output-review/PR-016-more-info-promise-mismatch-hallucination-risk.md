# PR-016: More info link promises specific live-event verification but resolves to unvalidated claim-text search query

Labels: `review:v1.4-output`, `type:bug`, `status:open`, `severity:high`, `area:ai-content`, `area:content-linking`, `area:url-validation`, `area:hallucination-risk`, `area:html-output`

Manifest: `trip_manifest.yaml`
Output Artifact: `output/index.html`
Baseline Version: `v1.4.0`
Review Source: manual output review

## Summary

A Telluride local tip claims users can check the Sheridan Opera House schedule for live music events, but the attached `More info` link is a generic Google search query built from the narrative sentence itself. This does not reliably deliver what the link promise implies (authoritative event/schedule source) and should be rejected when unverified/hallucinated.

## Expected Behavior

- `More info` links should resolve to a trustworthy, relevant target that actually supports the claim being made.
- If a claim-specific source cannot be validated, the link should be rejected (or omitted) rather than emit a claim-text search query.
- Hallucination-prone claim text should not be transformed directly into public search URLs.

## Actual Behavior

- The claim text about checking the Sheridan Opera House schedule is linked to:
  - `https://www.google.com/search?q=Check%20the%20Sheridan%20Opera%20House%20schedule%20for%20any%20live%20music%20events%20during%20your%20stay.%20It%27s%20a%20historic%20venue%20that%20frequently%20features%20local%20and%20touring%20artists.%20Telluride`
- This is an unvalidated search query generated from prose, not a direct schedule/event source.

## Evidence

- In [output/index.html](output/index.html):
  - line 1240 includes the local tip and the `More info` claim-text search URL
  - line 1332 repeats the same tip and same URL under Cultural Events

## Suspected Area

- Primary components: claim-to-link generation and link validation policy

  - [generator/html_assembler.py](generator/html_assembler.py)

## Root Cause Hypothesis

- Current fallback constructs search URLs from generated prose when an explicit trusted source is unavailable, without validating that the resulting URL fulfills the claim implied by link text.

## Scope of Likely Fix

- Enforce claim-support validation for `More info` links.
- Disallow prose-derived search-query URLs as final links for factual claims.
- Fail closed (drop link) when source verification cannot be satisfied.

## Non-Breaking Validation Plan

- Unit tests:
  - reject links generated by encoding full narrative claim text into search URLs.
  - require claim-supporting source patterns for event/schedule assertions.
- Integration checks:
  - regenerate Telluride output and verify the Sheridan tip either links to a validated source or appears without `More info` link.
