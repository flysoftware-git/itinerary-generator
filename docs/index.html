# Road Trip Generator Welcome to the Road Trip Generator project — an AI‑powered tool that transforms a minimal YAML manifest into a fully interactive, installable HTML itinerary. This GitHub Pages site provides: - Documentation - Examples - Links to generated itineraries - PWA versions of trips - Access to the repository README --- ## 📘 Project README For full instructions, environment setup, and manifest examples, see the main repository README: 👉 **[View README.md](../README.md)** --- ## 🧭 Generated Itineraries (PWAs) Below are examples of generated itineraries. Each one is a standalone PWA that can be installed on desktop or mobile. - **Reference itinerary** https://flysoftware-git.github.io/road-trip-generator/dev/ - **Southwest Road Trip** https://flysoftware-git.github.io/road-trip-generator/sw/ *(More itineraries will appear automatically as your generator outputs them.)* --- ## 🛠 Generator Overview The Road Trip Generator produces: - Daily schedules - Attraction descriptions - Restaurant recommendations - Scenic drives - Verified URLs - Destination images - Interactive maps - Installable PWA output It supports both: - **Single‑file HTML output** (Android‑installable) - **Full PWA output** (manifest, service worker, icons) --- ## 📂 Repository Structure
